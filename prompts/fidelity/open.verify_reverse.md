The merged document was produced at fidelity open. The merger could rewrite
prose freely, combine statements that repeated one another, complete fragments,
and state in general terms what a source stated about one occasion. A claim
that generalises a source's particular statement is SUPPORTED at this level,
and the evidence is the source span it generalises. A claim assembled from two
sources that genuinely say the same thing is SUPPORTED, and you name the one
you quoted.

This level may also combine complementary facts, so it has a fifth label that
the other levels do not:

DERIVED - no single source states this claim, and two or more source
statements entail it when taken together. The merger was permitted to write
it and the sources carry it jointly.

Quote one of the spans it was derived from in `evidence`, and name that span's
file in `evidence_source`; say in the rationale which other source statement
completes it. Use DERIVED only where a reader holding all those spans could
not accept them and reject the claim. Where the claim merely sounds reasonable
beside them it is not derived, and the label for it is MISSING.

That licence covers expression and joint support, and nothing else. A fact the
sources do not state, alone or jointly, is MISSING, however plausibly it fills
a gap and however well it fits the surrounding prose.

**Label it MISSING here even though this level permits the merge to add.**
Whether a statement was declared as an addition is not something you can see
and not something you should guess at: you are given the sources and the
merged claims, and your job is the same as at every other level, which is to
say whether the sources carry each claim. A declaration is reconciled against
your answer afterwards, by machinery that can read both. Softening a MISSING
because a claim looks like something the merge might have meant to add would
make that reconciliation read your guess instead of the merge's declaration,
and an undeclared invention would pass.

This level also permits a covering value where the documents disagree about
the edges of one figure. A claim giving a range is SUPPORTED when every number
in it is a number some source states, and the range spans what the sources
gave: 30-50% against sources saying 30-45% and 35-50% is supported, because a
value in either source's range is a value in this one. Quote one of those
source spans as the evidence and name the other in the rationale.

It is a narrow licence and the bound is arithmetic you can check by reading.
A range carrying a number no document states is not covered by it and is
MISSING, however reasonable the number looks. A merge that widened 30-45% to
30-60% has told the reader something no source did.

Settings

How hard the model thinks while it writes the merge. Higher is slower and usually costs more.

How thoroughly to check

A benchmark was run, but its figures are not loaded on this server, so how much the cheaper check misses is unmeasured here, which is not the same as nothing. Shown instead: the calls it saves, and what it does not check.

Tuning

The merge may openly leave out up to this share of your documents, and lists every omission. Over it, you still get the merged document, marked for review. The report calls this the declared-loss ceiling.

Title

"keep-base" keeps the base document's title, or the first title in document order if the base has none. "choose-best" takes the clearest existing title and never writes one. Only "synthesise" may write a new title, and that title is checked against your documents like any other fact.

Nothing is reported when no document has a title and the merge writes none, or when the merged title's words already appear in a document's text. A first line that runs straight into the text is not counted as a title.

    About this list
    
                      
    
                      
    
                      
    
                      A tool that runs as a program on this server is set up by whoever runs the server. From a browser you can only switch on the tools the server found on its own machine, under Credentials. The command itself is never sent to a browser.
                      
    
                      A self-hosted row has no cost per merge, because its GPU is billed by the minute, not by the token. The cell says "per GPU-minute" instead of showing a zero: it is not free, and it cannot be compared with the per-token prices of hosted rows.

                      Cancel this run?
                      
  
                      
  
                      Calls already made are billed and cannot be undone. Cancelling stops any further calls: the run stops before its next model call, and a call still in progress is abandoned, which the provider may still bill. What ran so far is kept in the report.
                      
  
                      
    
    
  
                      
                      



  
                      
    
                      Retry this run?
                      
  
                      
  
                      This starts a new run from the same documents and settings. It runs from the beginning: every model call is made again, and calls may be billed again, including any the stopped run already made. The earlier run stays in the list, and the new one links to it.
                      
  
                      
    
    
  
                      
                      






  
                      
    
                      Clear this and start again?
                      
  
                      
  
                      The documents you pasted, the settings you changed and the result on screen are all cleared. There is no undo. The run itself stays on this server until its retention window passes, and it is still in the list of earlier runs.
                      
  
                      
    
    
  
                      
                      






  
                      
    
                      Reset your settings?
                      
  
                      
  
                      Your model, checking depth, wording level and tuning choices on this page go back to their defaults. Your saved defaults ("Save these settings as my defaults") are removed too, so this page starts from the server's own defaults next time. There is no undo.

# BIP: 39

## Abstract
This BIP describes a mnemonic code or sentence—a group of easy-to-remember words—for generating deterministic wallets. It consists of two parts: generating the mnemonic and converting it into a seed. The mnemonic-to-seed conversion produces a binary seed, not an ASCII seed. This seed can be later used to generate deterministic wallets using BIP-0032 or similar methods.

## Generating the mnemonic
ENT is a multiple of 32 bits. Allowed ENT values range from 128 to 256 bits. First, an initial entropy of ENT bits is generated. With more entropy security is improved but the sentence length increases. We refer to the initial entropy length as ENT. A checksum is generated by taking the first ENT / 32 bits of the SHA-256 hash of the initial entropy. This checksum is appended to the end of the initial entropy. The concatenated bits are split into groups of 11 bits, each encoding a number from 0-2047 that serves as an index into a wordlist. Finally, we convert these numbers into words and use the joined words as a mnemonic sentence. The following table describes the relation between the initial entropy length (ENT), the checksum length (CS), and the length of the generated mnemonic sentence (MS) in words.

```
CS = ENT / 32
MS = (ENT + CS) / 11

|  ENT  | CS | ENT+CS |  MS  |
+-------+----+--------+------+
|  128  |  4 |   132  |  12  |
|  160  |  5 |   165  |  15  |
|  192  |  6 |   198  |  18  |
|  224  |  7 |   231  |  21  |
|  256  |  8 |   264  |  24  |
```

## Motivation
A mnemonic code or sentence is easier for human interaction than handling raw binary or hexadecimal representations of wallet entropy. The sentence could be written on paper or spoken over the telephone. This guide is meant to transport computer-generated determinism in a human-readable transcription. It's not a way to process user-created sentences (also known as brainwallets) into a wallet seed.
